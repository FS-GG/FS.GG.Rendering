# S-DOC ledger — public api-surface entries a product skill does NOT name (#507)
#
# WHAT THIS IS. `template/base/docs/api-surface/**` is the signature set a generated product is GIVEN and
# which docs/scaffold-map.md designates authoritative. `template/product-skills/**` is what the product is
# TOLD. Nothing held the two against each other in EITHER direction, so the gap between them grew in
# silence: 242 of 428 public `val`s were named in no product skill at all — and among them were the ONLY
# instruments for the responsiveness evidence those same skills MANDATE (#507, epic FS-GG/.github#423).
#
# SurfaceDocCoverageTests (S-DOC) now holds them together: every public `val` in the shipped api-surface is
# either NAMED in a product skill, or listed HERE. This file is the declared half. Curation is legitimate —
# not every value wants a paragraph — but it must be a DECISION SOMEBODY MADE rather than an omission nobody
# noticed, and that distinction is the entire issue.
#
# THE LEDGER CANNOT ROT. S-DOC fails three ways, not one:
#   * a public val neither documented nor listed here    -> the gap grew, and silently. The #507 shape.
#   * a listed val a skill NOW documents                 -> stale exemption. Delete the line.
#   * a listed val the api-surface no longer ships       -> stale exemption. Delete the line.
# So the ledger can only shrink by documenting, and it cannot outlive its subjects. Without the last two, the
# cheapest response to a growing gap would be to append here, and this file would become the record of the
# problem instead of its fix.
#
# FORMAT:  <category>  <name>
#
#   tracked     A surface a product author would WANT and cannot find. A real gap, tracked by #507 / epic
#               FS-GG/.github#423 — listed, NOT blessed. These are the ones to write next.
#   vocabulary  A constructor or combinator in a type's own vocabulary (a scene shape, a colour, a design
#               token, a geometry helper). A product composes it straight from the `.fsi`, and a skill that
#               listed them would be a worse copy of the signature file.
#
# `vocabulary` is a CLAIM, and it is deliberately visible so it can be challenged. If one of these deserves
# prose, move it: delete the line and write the paragraph. Down is the intended direction of travel.
#
# Documenting a surface is constrained by R-REACH (#430): a skill may only name APIs every profile it
# materializes on actually receives. Find the skill whose profile gate matches the package's reach — not the
# one whose subject matter feels closest.
