# Phase 1 Data Model: Persistence (save/load) effect surface

Feature `244-persistence-effect-surface`. Entities are pure F# values in the `FS.GG.UI.Canvas`
namespace (module `Persistence`). See `contracts/Persistence.fsi` for the exact signatures.

## Entities

### `PersistenceEffect` (discriminated union)

A requested save/load action, emitted as a value from a product's pure `update`. Data only — never
a filesystem handle, stream, or IO.

| Case | Fields | Meaning |
|------|--------|---------|
| `Save` | `envelope: SaveEnvelope` | Persist a versioned, product-serialized payload to a slot. |
| `Load` | `slot: SaveSlot` | Request the contents of a slot (the result is dispatched back to the model by a deferred host backend). |
| `DeleteSlot` | `slot: SaveSlot` | Remove a save slot. No-op if the slot is empty/absent. |

**Validation rules**:
- The DU carries only plain data; no case references a filesystem, stream, or effectful closure.
- `Load` / `DeleteSlot` of an unknown slot are valid request values — recorded faithfully by the
  headless interpreter, never thrown on (Principle VI). "No such save" is a deferred-backend concern.

**Notes**: The vocabulary is intentionally minimal (the game-default gap). Richer persistence
(enumerate slots, save metadata/thumbnails, migration helpers) is a future **additive** DU extension
and does not change the record-only interpreter seam.

### `SaveEnvelope` (record)

The versioned wrapper the product author fills in before a `Save`.

| Field | Type | Meaning |
|-------|------|---------|
| `Version` | `int` | Product-stamped save-format version, normalized to `>= minVersion`. Enables a future load to migrate or reject old saves. |
| `Slot` | `SaveSlot` | Target save slot. |
| `Payload` | `SavePayload` | Opaque, product-serialized save data. |

**Validation rules**: `Version` is clamped to `>= minVersion` by the `saveEnvelope` smart
constructor and re-normalized when recorded — never rejected or thrown on (Principle VI). The
framework never parses, validates, or re-encodes `Payload`.

### `SaveSlot` / `SavePayload` (single-case DUs over `string`)

Opaque, product-owned values. `SaveSlot` names a save location; the framework does **not** own the
slot → path mapping. `SavePayload` is already-serialized save data; the framework carries it verbatim
and does **not** own the on-disk format (kept out of the library, mirroring how per-game stat mapping
is kept out of symbology). A product resolves/serializes these in its own host and model layers.

### `PersistenceEvidence` (record)

Ordered proof of what a product requested, produced by the record-only interpreter.

| Field | Type | Meaning |
|-------|------|---------|
| `Requested` | `PersistenceEffect list` | Requested effects in dispatch order (oldest first), with Save versions normalized and payloads carried verbatim. |

**State transition**: `emptyEvidence` → `record e1` → `record e2` → … accumulates in order.
`interpret [e1; e2; …]` is the batch fold producing the final `PersistenceEvidence`. This is the
headless-safe host boundary for the minimal slice: no filesystem access, never blocks, never throws
(FR-005/FR-006). It is **real** evidence of requests (not synthetic save I/O), so no `Synthetic`
disclosure applies.

## Relationships & boundaries

```
product update  ──emits──▶  PersistenceEffect  ──record/interpret──▶  PersistenceEvidence  ──asserted by──▶ tests
                                   │
                                   └──(deferred)──▶ real file backend in SkiaViewer host
                                        (consumes the same PersistenceEffect values; on Load,
                                         dispatches a loaded-result Msg back to the model; surface unchanged)
```

- **Owned by this feature**: `PersistenceEffect`, `SaveEnvelope`, `SaveSlot`, `SavePayload`,
  `PersistenceEvidence`, module `Persistence`.
- **Not owned**: slot→path resolution and payload serialization (product), real save I/O and the
  load-result Msg dispatch (deferred backend).
- **Package placement**: all of the above live in `FS.GG.UI.Canvas` (module `Persistence`),
  Scene-only, no new dependency. Delivered to `game`/`sample-pack` products via the existing Canvas
  package gate.
