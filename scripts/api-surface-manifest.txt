# THE CURATION — the input the pinned package cannot carry (#752 / #694).
#
# `scripts/refresh-api-surface-mirror.fsx` emits `template/base/docs/api-surface/**` from the .fsi the
# PINNED packages ship, and this file is everything the package cannot know: WHICH of the pin's 2,575
# members are taught (the mirror declares 1,294 — omission is the DESIGN, and M-MIR is coherence
# "never completeness"), which of the pin's 114 .fsi merge into which of the 62 mirror files, the
# `// See skill:` pointer M-PTR requires (0 of the packed .fsi carry one), and the handful of doc
# blocks the pin is SILENT on.
#
# THE PIN IS AUTHORITATIVE FOR PROSE, AND THIS FILE DOES NOT SECOND-GUESS IT. `scaffold-map.md` says
# it outright — "when they disagree, the `.fsi` wins" — so wherever the pin documents a member, its
# text is emitted verbatim and there is no entry here. `prose`/`proseat` exist for exactly one case:
# the pin says NOTHING and the mirror taught something (six blocks, e.g. `KeyboardEffect`'s
# "Issue 456: NOT INTERPRETED BY ANY HOST" warning, which sits on a union case the pin leaves bare).
#
# That rule is not a preference, it is the point of the item. Measured at the 0.11.0 pin, EVERY one of
# the 98 members both sides documented had text that DIFFERED — sometimes because the mirror was a
# stale copy (`Neighbourhood.FourWay` taught "each move costs 1 (`bfs`) / 10 (`astar`)"; the pin has
# said `baseStep` since Game.Core 0.5.0), sometimes because the mirror added teaching the pin lacks.
# Nothing mechanical tells those apart — `module Physics` does BOTH inside one doc block — so an
# "override wherever they differ" rule would have checked 63 stale doc blocks in as curation and
# called the drift a decision. The mirror NETS +368 doc lines under this rule, because the pin's docs
# are the richer ones.
#
# THE "91 SCAFFOLD-ONLY SENTENCES" WERE TRIAGED IN #849, AND THE NUMBER WAS AN ARTEFACT OF HOW IT WAS
# COUNTED. It came from a sentence-level diff of the old mirror against the new, which reports a
# sentence as "dropped" when its TEXT does not survive — and the rule above rewords essentially every
# sentence it keeps. Both examples this header used to offer as teaching-the-pin-lacks are in the pin
# verbatim: `Persistence`'s "It is evidence of intent, NOT of durability" and `Physics`'s "Arcade
# resolution stays the first-class default".
#
# The tally is not the error — the CATEGORY is. Re-running that count reproduces it (80 here, 91 there;
# the same method, and the gap is only where a splitter ends a sentence). What it cannot do is tell a
# REWORDING from a LOSS, and under a rule that rewords everything it keeps, almost every hit is the
# former. Re-measured for surviving CONTENT against the whole file rather than sentence-to-sentence:
# SIX sentences, in three doc blocks, lost their teaching. The rest is this rule working.
#
#   * `Physics` (31 of the 91, the largest block) drops NOTHING. All of it is reworded, and the pin is
#     richer in nearly every case — it adds the parentheticals the mirror lacked.
#   * `Pathfinding`'s 5 are STALE — they are the `10`/`14`-vs-`baseStep` case this header already cites.
#     Route 3: already gone, correctly.
#   * `KeyboardInput`'s 5 were ALREADY UPSTREAM, on `mapKeyRaw` (#456/#523) — and the mirror's version
#     is stale: it taught "you write the forwarding seam yourself", which is what `mapKeyRaw` exists to
#     stop. The pin will carry it when $(FsGgUiVersion) moves past 0.11.0.
#   * Genuinely lost, and now upstream: `TextInput.update`'s effect round-trip (no framework function
#     maps a raised effect back to a `Msg`, and there cannot be one), `interpretRecordOnly`'s naming
#     rationale (both are #537's retirement of an inert member, and the note is what stops the next
#     reader restoring it), and `ScrollState`'s "Carried by `ControlRuntimeModel.ScrollOffsets`".
#
# So there is no cross-repo prose debt: the 13 cross-repo mirror files (Game.Core x9, Audio.* x4) need
# no ask, because none of them lost teaching. CHECK `src/` BEFORE CONCLUDING THE MIRROR LOST ANYTHING —
# the mirror is generated from the PINNED .fsi, so prose already in `src/` reads as missing until the
# pin moves, and that alone accounted for 5 of the 91.
#
# THIS FILE IS AUTHORED. It was DERIVED once, mechanically, from the mirror as it stood at
# FS.GG.UI 0.11.0 / FS.GG.Game.Core 0.5.0 / FS.GG.Audio 0.3.0 — that is why it reads like a machine
# wrote it — but it is an INPUT from here on. To teach a symbol the pin exports, add a `+` line. To
# stop teaching one, delete its line. Never regenerate this from the mirror: the mirror is this file's
# OUTPUT, and deriving the input from the output is a gate that compares a thing to itself and agrees
# (#661) — the loss would look exactly like the intent.
#
# GRAMMAR
#   file    <path under template/base/docs/api-surface>
#   skill   <product skill name>              -> `// See skill: <name>`  (M-PTR requires it)
#   header  <verbatim comment line>           -> emitted under the skill pointer
#   ns      <namespace>
#   pkg     <pinned package the members come from>
#   open    <namespace>                       -> emitted after `namespace`, in listed order
#   +       <pin .fsi> <kind> <dotted path>   -> teach this member, here, in this order
#   prose   <pin .fsi> <kind> <dotted path>   -> the following `| ` lines REPLACE the member's doc
#   proseat <pin .fsi> <kind> <path> ::: <anchor>
#                                             -> the `| ` lines REPLACE the doc block above the line
#                                                whose text is <anchor>, INSIDE that declaration (a
#                                                union case has no lead of its own to override)
#
# A `+` naming a member the pin does not export is a hard error, not a skip; so is a `proseat` whose
# anchor the pin no longer has. That is the point — it is the drift #694 was filed about, and it can
# no longer be silent.

# =============================================================================================
#
# The mirror teaches roughly half the pin's public surface by design (see the header above:
# "omission is the DESIGN"). Until #925 that omission was SILENT: `refresh-api-surface-mirror.fsx`
# maps this manifest onto the pin and fails on drift, but nothing checked the reverse — a public
# member the pin SHIPS that no `+` line teaches merged into the mirror untaught, green, taught
# nowhere in the scaffold. That is how 0.13.0 shipped #911's key-wiring surface with the mirror
# omitting it for the whole #912 window (PR #924 fixed it by hand; nothing would have flagged it).
#
# The gate now reconciles the pin's public `type`/`val`/`and` surface against (taught ∪ waived) and
# fails on any member that is neither. Each line below is that decision made EXPLICIT: "we ship
# this, and we deliberately do not teach it." Omission is still the design — it is just no longer
# by silence.
#
# GRAMMAR:  waive <package> <source.fsi> <kind> <dotted.path>
#   — the same (pkg, source, kind, path) key the `+` includes use. Per-member, NEVER a wildcard: a
#     `waive Module.*` would swallow the NEXT member added under `Module` too, reintroducing the
#     exact "untaught by silence" this gate closes. So a new public member is unwaived by default
#     and forces a maintainer to decide: teach it (a `+`), or waive it (a line here).
#
# STALE WAIVERS ARE A HARD ERROR. A `waive` whose member left the pin (removed/renamed) or is now
# TAUGHT waives nothing; the gate reds on it, so this list cannot accrete dead entries the next real
# omission hides behind (#266).
#
# REGENERATE (after a pin bump adds/removes members): re-seed the whole block from the current pin —
#   dotnet fsi scripts/refresh-api-surface-mirror.fsx --emit-waivers
# — then reconcile teach-vs-waive by eye: a newly-shipped member lands here by default; MOVE it to a
# `+` in the right file stanza if the scaffold should teach it. Kept sorted by (package, source,
# path, kind) so a diff shows exactly which members entered or left the pin's surface.
